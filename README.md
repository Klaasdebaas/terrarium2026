# terrarium2026
Terrarium-besturing met ESP32-C6 (Arduino IDE): temperatuur- en vochtigheidsregeling,
verlichtingsschema, logboek op SD-kaart, storingsmeldingen per SMS (SIM7600) en een
lokale webinterface.
